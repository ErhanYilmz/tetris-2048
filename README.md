# Tetris 2048 Fusion 🎮

A unique, addictive puzzle game that flawlessly fuses the iconic falling-block mechanics of **Tetris** with the strategic, sliding number-merging logic of **2048**. 

This project bridges the gap between rapid spatial awareness and calculated arithmetic planning. Built completely in Python, it challenges players to manage gravity-driven blocks while aligning matching powers of two to reach the ultimate tile before the board fills up.

## 🌟 Key Features

* **Hybrid Core Gameplay:** Control falling blocks that carry numeric values. When two blocks with identical numbers collide, they instantly merge and double in value.
* **Classic Tetris Controls:** Full support for standard mechanics including smooth left/right shifting, soft drops, hard drops, and rotational adjustments.
* **Exponential Scoring System:** Combines traditional Tetris line-clearing rewards with 2048's tile-merging multiplier mechanics for high-stakes, competitive high scores.
* **Clean Python Architecture:** Developed with highly modular, lightweight, and well-documented code, making it an excellent blueprint for custom feature implementations.
